## CRITICAL

### C1 — Merge runtime markers not gitignored → every parallel GREEN landing spuriously reverted
`merge.mjs:85` · false-green / data-loss
`merge.mjs` writes `control/.merge-tick.json` (before every `runBookkeep`) + `control/.merge-regate-fails.json`.
Neither is in `cosmo-canyon/.gitignore` nor bookkeep's `ALLOW_CONTROL`. bookkeep's tree-wide scope guard
(`bookkeep.mjs:655-657`) sees `?? cosmo-canyon/control/.merge-tick.json` → `tamper: out-of-scope edit` →
`fullRevert` (`:710-711`) discards the worker's real src, `bumpAttempt` marches the bead to abandonment
(ABANDON_N=3), merge records `reverted` + `bumpRegateFails` → auto-drops maxConcurrency to serial.
`revertOnePath` also deletes merge's own live anchor + counter mid-op. **Parallel mode (LIVE per config.json)
can never land any work.**
Fix: add `control/.merge-*.json` to `.gitignore` + bookkeep `ALLOW_CONTROL` (or relocate under `control/locks/`).

### C2 — Control plane binds all interfaces (0.0.0.0/::), zero auth
`server.mjs:1013` · security/exposure
`server.listen(PORT)` — no host arg → binds unspecified addr, LAN-reachable. No token/origin/referer check.
Any host reaching :7788: `POST /rollback` → `git reset --hard cc-known-good` + `git clean -fd cosmo-canyon`
(`:537-538`) wipes uncommitted work; `POST /start` burns token budget; `/assets/*` (the `/gdd` route cited here was later REMOVED with the GDD, 2026-07-02).
Verify caveat: bounded by LAN-adjacency + host firewall (localhost dev tool) — real but scoped.
Fix: `server.listen(PORT,'127.0.0.1')` (+ `::1`); gate mutating routes behind a per-session token.

### C3 — No CSRF + wildcard CORS → any visited web page drives the control plane
`server.mjs:998` · security/csrf-cors
`Access-Control-Allow-Origin: *` + OPTIONS→204, no Origin/CSRF check. Malicious page in the operator's browser
POSTs cross-origin to `localhost:7788` → start/stop loop, create/delete assets, plant
stored XSS (see H2). *(The "ingest attacker GDD" vector cited here is GONE — GDD ingest REMOVED 2026-07-02.)* Note: `readJsonBody` ignores Content-Type, so even a preflight-free simple request lands.
Fix: Origin allowlist (Launcher only) + drop wildcard ACAO on mutating routes + CSRF token.

## HIGH

### H1 — Untracked out-of-scope DIRECTORY survives fullRevert → payload persists → committed tree-wide
`bookkeep.mjs:194` · security/persistence (Windows-specific)
`revertOnePath` uses `git rm -f --ignore-unmatch p` (no `-r`) + `rmSync(abs,{force:true})` (no `recursive`).
`git status --porcelain` collapses an untracked dir to `evil/`; `git rm` no-ops on untracked, `rmSync` throws
EISDIR (swallowed by try/catch) → dir survives. `git clean -fd` is scoped to `game`. Next `RALPH_PASS`-unset
Stop hook `git add -A` commits it tree-wide. §15.41 anti-persistence hole — closed for files, open for dirs.
Fix: `rmSync(abs,{recursive:true,force:true})` + `git rm -rf`; post-revert tree-wide porcelain re-check that
hard-fails on any residual non-allowed path.

### H2 — Attribute-context XSS: ccEsc doesn't escape quotes
`ui/index.html:226` · security/xss
`ccEsc` escapes only `& < >`. `filename` (`:412 title="…"`) and planner-supplied bead/suggestion `id`
(`:323/:330 onclick="…('…')"`) break out of the HTML/JS-string context → arbitrary JS in the :7788 origin.
`filename` stored raw (`server.mjs:703` slice-only; `assets.mjs:130`); `b.id` planner-LLM verbatim
(`plan-apply.mjs:78`, no charset validation → a prompt-injected spec/instruction is a real vector; the GDD-import
injection path originally cited here is GONE — GDD REMOVED 2026-07-02). Rendered via innerHTML on
the 3s poll = persistent stored XSS.
Fix: escape `'`→`&#39;` and `"`→`&quot;` in ccEsc; build handlers via setAttribute/addEventListener; validate
`b.id` charset in plan-apply (reuse ID_RE); sanitize filename on create.

### H3 — Image render-reachability grader accepts `declare('<key>')` (false-green) [verify→medium]
`game/accept/_image-grader.ts:57`
`declare` (registry.ts:89-109) is render-inert — only inserts a manifest entry, never fetches/draws — behaves
exactly like the explicitly-EXCLUDED `getEntry`, yet is on the accepted call list. A `declare('<key>',{...})`
reference passes grader step 3 → asset reaches Implemented while nothing renders it.
Fix: remove `declare` from the refRe alternation (leave `getTexture|makeSprite`).

### H4 — Enemy sprite texture bound to pool slot on first sight, never updated
`game/src/render/stage.ts:127`
Enemies/minibosses/bosses share one `s.enemies` Pool (LIFO slot reuse). `spriteFor(e)` caches a Sprite per
`e._slot` and picks the texture from `e.kind` ONCE at creation. A freed grunt slot reused by a boss →
**boss drawn with the grunt texture** (wrong size/anchor). Also `this.sprites` is never cleared on `beginRun`
→ stale cross-run sprites accumulate in `enemyLayer`.
Fix: re-key the sprite on the CURRENT `e.kind` (swap texture/anchor on mismatch); reset the renderer at run start.

### H5 — Chest upgrade draft silently overwritten by a same-tick level-up draft
`game/src/sim/systems/combat.ts:76`
Tick order spawn→…→combat→pickup→…→upgrade. Chest collect sets `pendingUpgrades`; same-tick XP level-up makes
`upgradeSystem` (`upgrades.ts:72`) unconditionally rebuild `pendingUpgrades`, clobbering the chest draft (no
already-pending guard). Multiple chests in one tick also collapse to one draft. Lost reward.
Fix: early-return when `pendingUpgrades.length>0`; queue extra drafts, process one at a time.

### H6 — Workflow host mis-attributes an orphan-only merge cycle as 'reverted' → spurious breaker/auto-pause
`orchestrator/cc-loop.workflow.js:188`
Host sets `lastOutcome='reverted'` when `landed===0`; supervisor keys on actual reverts
(`anyRevert=(reverted+conflicts+red)>0`, else 'idle'). An all-workers-crashed cycle (orphans>0, reverted=0) is
a benign infra-kill supervisor idle-retries, but the host trips the §15.20 breaker → auto-pause.
Fix: mirror supervisor — `anyRevert = (mg.reverted+mg.conflicts+mg.red)>0; lastOutcome = anyRevert?'reverted':'idle'`.

### H7 — maxConcurrency has no upper clamp
`orchestrator/config.mjs:48`
`clampInt(c.maxConcurrency,1,2)` only floors the low end; a valid large int passes untouched.
`"maxConcurrency":999` (typo/bad GUI edit/hostile write) → `schedule.mjs:117` opens up to 999-active slots →
`dispatch.mjs` spawns that many worktrees + workers → resource exhaustion. merge auto-drop only reduces AFTER
reverts. "malformed can never widen" holds; a valid large value does widen.
Fix: `const MAX=2; mode==='serial'?1:Math.min(MAX, clampInt(c.maxConcurrency,1,2))`.

## MEDIUM / LOW

### M1 — Binary worker diff hard-fails apply → green worktree falsely treated as unmergeable conflict
`merge.mjs:73` · `workerPatch()` uses `git diff baseSha` (no `--binary`); `applyPatch()` `git apply --3way`
then plain `git apply` (no `--binary`). Any binary under `game/` (PNG/audio/.ico/.wasm) → textual
"Binary files differ" hunk → apply refuses → conflict branch → retries identically forever.
Fix: `git diff --binary` + `--binary` on both applies (or `git checkout <sha> -- <path>` for binary paths).

### M2 — Flipbook static-check only compares frames #0 vs #1
`game/accept/_image-grader.ts:81` · Frames #2..#N-1 never checked. `derive.mjs sliceFrames` zero-fills columns
past source width, so a too-narrow strip yields blank trailing frames that pass. Ships "N-frame flipbook" with
blank frames.
Fix: compare all adjacent frame pairs; reject any frame with 0 non-zero-alpha pixels; clamp `frames` in derive.

### M3 — Enemy zone/mini-boss speed stat written but never read
`game/src/sim/systems/movement.ts:68` · `spawn.ts` sets `e.speed` (zone `speedMult`, MINI_BOSS.speed=80) but
`movementSystem` uses `enemySpeed(e)=70+(e.id%7)*2`, ignoring `e.speed`. Entire `ZONE_PROFILES.speedMult`
column is dead; mini-boss moves generic ~70-82 not 80.
Fix: use `e.speed` for non-boss enemies (fallback `enemySpeed` if 0); set MiniBoss/forest `e.speed` on spawn.

### L1 — Renamed/quoted porcelain entries produce un-revertable path strings
`bookkeep.mjs:242` · `dirtyPaths()=l.slice(3).trim()`; a rename `R  old -> new` yields the literal
`old -> new`, so `revertOnePath` operates on a nonexistent path. Narrow impact (game renames covered by scoped
checkout+clean). Fix: parse porcelain `-z` (NUL-delimited); split rename entries into two real paths.
