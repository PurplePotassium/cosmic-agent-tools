## DEFERRED (assessed, not fixed) — with rationale

- **#2 HIGH — junction blast radius** (`worktree.mjs:122`): `git worktree remove --force` follows junctions and
  deletes the shared target; only the `node_modules` junction is dropped first. A worker planting `mklink /J`
  elsewhere under its worktree/game gets that target deleted at cleanup. Same adversarial-worker ceiling as #1
  (a worker with FS write access can `rmSync` directly anyway), and a general lstat-walk-and-unlink is
  higher-risk to implement. With #1's root pin the removal is confined under `C:/Vibes-cc-wt/`. Recommend a
  reparse-point sweep before destructive removal when hardening the parallel path further.
- **#7 HIGH — no loop-host mutex** (`supervisor.mjs`/`preflight.mjs` never take `.cc-host.lock`, spec'd
  PLAN.md:844): supervisor boot mid-Workflow-tick → `resetGameTo(baseSha)` under a live agent + double loop.
  Needs cross-host coordination + testing to avoid introducing a deadlock; a hasty half-fix is riskier than the
  gap. The 13.23 cross-system mutex partially covers concurrent cc-start. Fix deliberately, not in this pass.
- **#1 residual — config.json in ALLOW_CONTROL**: kept committable (GUI live-edits mode/maxConcurrency/
  tickBudget must survive a tick revert); the dangerous field (worktreeRoot) is now ignored, so the residual is
  bounded to already-clamped fields.
