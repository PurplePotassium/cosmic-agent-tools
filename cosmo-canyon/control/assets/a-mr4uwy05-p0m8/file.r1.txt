CREATE src/sim/adventure.ts (PURE data + pure helpers only — no rng-at-module-load, no persistence, no DOM, no imports from render or harness):
- Define and export `type Biome = string` (biome names align with worldmap HEX_LIST `type` values: 'Forest','Desert','Ocean','Snow','Mountain','Ashen','Swamp','Dungeon','Tower'). 
- Define and export `interface StageDescriptor { biome: Biome; events?: string[] }` — one entry per stage; `events` is an optional list of unique-event ids for that stage (may be empty/omitted for now).
- Define and export `interface AdventureDef { id: string; name: string; narrativeId: string; stages: StageDescriptor[] /* exactly 5 */ }`. Include an exported constant pool `ADVENTURES: AdventureDef[]` with at least 3 authored adventures, each with exactly 5 StageDescriptors and a distinct narrativeId. Export a lookup `getAdventure(id: string): AdventureDef | undefined`.
- Define and export the RUNTIME progress shape `interface AdventureProgress { adventureId: string; stageIndex: number /* 0-based, 0..4 */; party: string /* selected character id 'a'|'b'|'c' */; carriedWeapons: EquippedWeaponLike[]; carriedUpgrades: CarriedUpgrade[]; stats?: AdventureStats }` where `EquippedWeaponLike` mirrors the sim's EquippedWeapon fields you need to restore ({ weaponId, level, timer, rarity }), and `CarriedUpgrade` is a small data object `{ kind: string; value: number }` describing a per-Adventure buff applied at run start (e.g. { kind:'maxHpBonus', value:25 } or { kind:'damageMult', value:0.10 }). Add `interface AdventureStats { kills: number; totalDamageDealt: number; elapsedSec: number; stagesCleared: number }` accumulated across the Adventure.
- Export pure helpers (no side effects, no rng unless a seed is passed in): `currentStage(p: AdventureProgress, def: AdventureDef): StageDescriptor` (returns def.stages[p.stageIndex]); `isLastStage(p, def): boolean` (stageIndex === def.stages.length-1, i.e. index 4); `advanceStage(p): AdventureProgress` (returns a NEW progress object with stageIndex+1 — do not mutate input); `applyCarriedToGameState(state: GameState, p: AdventureProgress): void` which, at run start, restores `state.player.weapons` from p.carriedWeapons (deep-copied) when non-empty, applies each carriedUpgrade to the state (maxHpBonus adds to maxHp then heals to new max; damageMult stored on a field the weapons system can read OR applied as a documented approximation — pick the least invasive correct option and comment it), and sets `state.environmentType` to `currentStage(p,def).biome`. `harvestCarriedFromGameState(state, p): AdventureProgress` returns a NEW progress with carriedWeapons snapshotted from state.player.weapons (deep copy) and stats accumulated (kills += state.kills, totalDamageDealt += state.totalDamageDealt, etc.) — used between stages so weapons+upgrades persist. Keep every helper deterministic and free of Math.random/Date.now.
