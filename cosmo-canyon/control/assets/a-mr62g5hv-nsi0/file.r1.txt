## weapons_core_gdd

GOAL: Add the seven straightforward projectile / AoE / aura weapons from the GDD to the game's weapon system so each is addable via addWeapon() and fires deterministically. This is a Cosmo Canyon Ready Spec for Realm Survivors (Vite + TS + PixiJS v8, deterministic sim + Pixi renderer).

## weapon_levels_5

GOAL: Raise the weapon maximum level from 3 to 5 everywhere it is hardcoded, and replace the current flat `damageForLevel` curve with a data-driven per-level scaling model so leveling from 1 to 5 is deterministic and the level-up draft keeps offering an 'upgrade this weapon' card until the weapon reaches level 5.
